# FS Error Codes

| Code | Severity | Message | Applies To |
|------|----------|---------|------------|
| `FS-1` | `CRITICAL` | Missing translation | all types |
| `FS-2` | `WARNING` | No level 1 heading found | `language` |
| `FS-3` | `CRITICAL` | No Dialob form defined | `service` |
| `FS-4` | `CRITICAL` | Service has no flow defined and cannot process customer requests | `service` |
| `FS-5` | `WARNING` | Asset in disabled mode and will not appear on the client-facing side | all types |
